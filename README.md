# Project Git

Учебный проект по МДК.05.02.

## Автор
Игорь Долотов

## Описание
Демонстрационный репозиторий для изучения Git, GitHub, C# и Node.js.
## Задание 9: Работа с ветками Git

В этом задании освоены:
- создание ветки `feature/notes-readme`;
- коммит изменений в ветке;
- отправка ветки на GitHub через `git push -u`;
- создание Pull Request;
- слияние (Merge) в основную ветку `main`.
## Команда проекта и права доступа

Репозиторий использует модель ролевого доступа GitHub:

| Роль | Имя | Права GitHub | Обязанности |
|------|-----|--------------|-------------|
| Администратор проекта | 2L8GO | Admin | Управление репозиторием, слияние PR, защита веток |
| Разработчик | Ivan Petrov | Write | Разработка серверной части, коммиты, создание PR |
| QA-инженер | Maria Sidorova | Triage | Тестирование, создание Issues, управление задачами |
| Технический писатель | Alexey Smirnov | Read | Документация, комментарии к коду |

### Распределение обязанностей

- **Admin** имеет полный доступ: управляет участниками, настраивает защиту веток, может удалить репозиторий.
- **Write** позволяет пушить код в репозиторий, создавать ветки и сливать Pull Requests.
- **Triage** позволяет управлять Issues и PR без доступа к коду (актуально для тестировщиков).
- **Read** — только чтение: просмотр кода, комментарии, создание Issues.
