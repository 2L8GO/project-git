## Задание 9: Работа с ветками Git

В этом задании освоены:
- создание ветки `feature/notes-readme`;
- коммит изменений в ветке;
- отправка ветки на GitHub через `git push -u`;
- создание Pull Request;
- слияние (Merge) в основную ветку `main`.
